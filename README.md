# mc-mods-manager

`mc-mod` is a CLI with a local web UI for managing Minecraft mods and plugins. It can list installed
content, search Modrinth and CurseForge, install the right version for the instance, and export
server-side mods.

Work in progress. Start with [AGENTS.md](AGENTS.md) and [artifacts/](artifacts/).

```sh
bun install
bun run dev
```
